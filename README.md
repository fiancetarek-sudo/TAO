# TAO — مركز القيادة اليومي

واجهة عربية RTL متجاوبة لمتابعة العمل اليومي. هذه النسخة **واجهة ثابتة تجريبية** وليست متصلة حتى الآن بالبريد أو التقويم أو واتساب أو مكتبة الملفات.

## الملفات
- `index.html`: بنية الواجهة والأقسام.
- `style.css`: التصميم المتجاوب.
- `app.js`: التاريخ المحلي وتفاعلات التنقل البسيطة.

## تشغيل محلي
افتح `index.html` مباشرة في المتصفح، أو شغّل خادم ملفات ثابت من مجلد المشروع.

## النشر عبر GitHub Pages
1. افتح إعدادات المستودع: https://github.com/fiancetarek-sudo/TAO/settings/pages
2. من **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/(root)`.
4. اضغط **Save** وانتظر اكتمال النشر.
5. تحقق من رابط النشر الذي يعرضه GitHub في صفحة Pages.

قد يستغرق أول نشر بضع دقائق. لا يُعد الموقع منشورًا قبل ظهور حالة النشر والتحقق من فتح الرابط.

## الخصوصية والأمان
- المستودع عام؛ لا تضف إليه بيانات بريد أو تقويم أو ملفات شخصية أو معلومات عمل سرية.
- لا تضع OAuth tokens أو API keys أو كلمات مرور في ملفات الواجهة.
- ربط الخدمات الخاصة يتطلب لاحقًا طبقة خلفية آمنة (backend) وموافقة صريحة على الصلاحيات.
- كل الأسماء والأرقام والمواعيد والملفات المعروضة حاليًا أمثلة توضيحية غير حقيقية.

## خارطة الطريق
1. اعتماد التصميم والحقول المطلوبة.
2. إعداد Backend آمن لمصادر البيانات التي يوافق المستخدم على ربطها.
3. عرض حالة اتصال كل مصدر ووقت آخر تحديث.
4. إضافة قسم واتساب فقط بعد إعداد تكامل رسمي وآمن.
